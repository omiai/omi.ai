# プロンプト:日本の結婚相談所システム解説ページ(海外向け)の作成依頼

## 依頼の目的

海外の方(日本語を母語としない読者)に向けて、**日本における一般的な「結婚相談所」というサービスがどのようなものであるか**を解説するウェブページを作成する。GitHub Pages で公開する静的な HTML ページとして制作する。

## 背景

- 秋葉結婚相談所は、日本最大級の結婚相談所ネットワーク(連盟)の加盟店である。
- そのため、本ページで解説する婚活の流れ・ルールは、その連盟の標準的な結婚相談所システムを踏襲した内容とする。
- **ただし、連盟の固有名称(ブランド名)は一切記載しないこと。**「日本最大級の結婚相談所ネットワーク」などの一般的な表現に留める。

## ページに含める内容(スコープ)

### 1. 大前提:お見合い結婚は「コントラクト・マリッジ(契約に基づく結婚)」である

- 結婚相談所を通じたお見合い結婚は、偶然の出会いから始まる「恋愛結婚(love marriage)」とは異なる文化・仕組みであることを最初に明確に説明する。
- 「結婚する」というゴールを最初から共有した者同士が、合意されたルールと期限感のもとで段階的に関係を深めていく、**構造化されたプロセス**であることを伝える。
- これは日本のお見合い文化の現代的な形であり、恋愛結婚より劣るものではなく、目的とアプローチが異なるだけであることを誠実に説明する。

### 2. 成婚までの4つのステップ

以下の流れを順番に、それぞれの意味・ルールとともに解説する。

1. **お見合い(Omiai / First Meeting)**
   - プロフィールを見て申し込み、双方の合意で成立する初回面談。
   - ホテルのラウンジ等で約1時間、お互いを知るための場。
2. **プレ交際(Pre-Kousai / Trial Dating)**
   - お見合い後、双方が「また会いたい」と思ったら始まる仮のお付き合い期間。
   - **この期間は複数の異性と同時並行でお付き合い・デートができる。**(詳細は下記セクション3)
3. **真剣交際(Shinken Kousai / Exclusive Dating)**
   - 結婚を前提に、一人に絞って交際する期間。
   - 真剣交際に入った時点で、他のすべてのプレ交際は終了する。ここからは一対一の排他的な関係となる。
4. **婚約成立(成婚 / Engagement)**
   - 双方がプロポーズ・婚約に至り、結婚相談所のプロセスが完了する。

### 3. 最重要の説明ポイント:プレ交際の同時並行は「浮気」ではない

- プレ交際期間中に複数の相手と同時にデートすることは、このシステムの**公式なルールであり、全員が事前に了解している前提**であることを誠実に、丁寧に説明する。
- 結婚相談所のお見合い結婚を目的とするコミュニティにおいて、これは「浮気(cheating)」や不誠実な行為には**該当しない**。
- 理由:
  - 参加者全員が同じルールに合意して活動している。
  - プレ交際は「相性を確かめるための試行期間」であり、恋人関係(exclusive relationship)ではない。
  - 排他的な関係は「真剣交際」に進んだ時点で初めて始まる、と明確に線引きされている。
- 海外の読者はデート文化の違いから誤解しやすいポイントなので、比較(例:排他性がいつ始まるかの文化差)を用いてわかりやすく説明する。

## ページに含めない内容(スコープ外)

- **料金設定・料金プランは記載しない。**
- **特定の店舗(秋葉結婚相談所を含む)を選ぶ利点・宣伝は記載しない。**
- **連盟の固有名称は記載しない。**
- 特定店舗への勧誘ではなく、あくまで「日本の結婚相談所という仕組み」の中立的・教育的な解説に特化する。

## 制作要件

- 海外の方向けのため、本文は**英語**で作成する(必要に応じて日本語の用語をローマ字併記:Omiai, Pre-Kousai, Shinken Kousai など)。
- GitHub Pages で公開できる静的な HTML(または Markdown)ページとして作成する。
- スマートフォンでも読みやすいレスポンシブなデザインとする。
- トーンは誠実・中立・教育的。文化的な違いを尊重し、誤解を解く姿勢で書く。
